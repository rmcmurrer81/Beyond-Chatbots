# Virtual Design Work

IdeaForge may update **virtual concept candidates** while background research is running.

These are research/design hypotheses, not fabrication-ready designs.

A virtual concept can combine known technologies, experimental research, project constraints, and selected references into a possible architecture to explore.

The virtual builder must keep:
- buildable-now elements;
- experimental elements;
- missing/speculative capabilities;
- assumptions;
- validation/simulation requirements

separate.
