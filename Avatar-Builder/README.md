# Avatar Builder

This folder contains generic observer, rest-persistence and body-feedback reference/development code. The connected_rest_observer_source_231 component retains its AGPL text, upstream attribution, transformation notice and failure/history documentation.

These libraries are not a complete portable builder or installer. Exact assets, body configuration, runtime caller closure, native motions and connected senses are not included or accepted by this package.

Current body source progress and historical prototype evidence have separate scopes. Source-only qualification does not establish native equivalence, pose, skin, breathing, blink, stretching, fingers, perception, audible speech or birth. Tongue/eye qualification and chest-isolation refusal remain unresolved.

Read REQUIREMENTS.md, RESULTS.md, the component notices and the package LICENSE-STATUS.md.
