# Help test — bounded checks and safe feedback

Current help is **document review**. Model/runtime tests await an approved executable release and its qualified commands. Please do not test private identities or upload personal data.

Choose one of these three checks. Each takes about three minutes and needs only the public files.

| Check | Steps | Expected result | Useful failure report |
| --- | --- | --- | --- |
| **1. Evidence counts and scope** | Compare the delayed-restart statements in the [latest update](../presentation/Latest-Speaking-Update.txt), [reviewed results](../presentation/Reviewed-Results.txt) and [short Q&A](../presentation/Very-Short-QA.md). | Version 14 reports three of four delayed restarts accepted, one pending; four migration reviews are a separate result. Preservation is not described as general reliable memory or conversation. | Exact public file and statement that differs. |
| **2. Attendee navigation and offline reading** | Open the links in [Start here](START_HERE.md). Download ZIP from the repository, extract it and open one small text document plus the slide PDF. | Published document links resolve and downloaded documents open without accessing private evidence. Large PDF/PPTX files may require downloading rather than GitHub preview. | Public link, viewer/platform category and a brief error description. |
| **3. Demo availability and truthful claims** | Read [demo](GENERIC_DEMO.md), [recording](DEMO_RECORDING.md) and [architecture](ARCHITECTURE_AND_GLOSSARY.md). | Pending execution/capture is explicit; planned arrows are not claimed as working connections; no personal state, cloned voice or general-performance claim is required. | A public phrase that appears misleading, with a suggested correction. |

These checks do not reproduce private research or qualify software. Report the public commit you examined; repository content may change.

## Before sending feedback

Use invented examples and share the smallest relevant excerpt. Remove names, contact details, usernames, home paths, hostnames, tokens, keys, private repository URLs, state/memory files, raw logs, personal images/audio and private experiment records. Do not attach a screenshot of unrelated tabs or your full desktop.

Use the existing contact listed in the [project overview](../README.md). This page sends nothing automatically. Do not create or publicly post a report containing sensitive information.

## Sanitized report template

```text
Public repository commit:
Check number: 1 / 2 / 3
Public file or link:
Platform/viewer category (no device name or username):
Steps followed (public material only):
Expected:
Observed:
Small sanitized excerpt (optional):
Suggested correction (optional):
Private data removed: yes / not applicable
```

## After executable release

The maintainer must replace the pending demo fields with exact approved commands, fixtures, output criteria and reset behavior. Pulse/control/repeat checks can then be offered against that same pinned package. No such runtime test is assigned by this page today.

For these document checks, reset means close the viewer or remove only the downloaded copy you created if you no longer need it. No service, database or model state was created by the check.
