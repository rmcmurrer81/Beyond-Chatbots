# NewBrain

This folder contains the exact reviewed GLIF starter source, evidence vocabulary, retained tests and clean nine-record research registry. The additional reference/routing directory contains 19 co-located routing/state/history/decoder libraries preserved from reviewed development source.

The starter is a small scientific demonstration, not a whole-brain clone. It uses the standard library. Some routing references require NumPy; no integrated public routing application, model weights or complete private runtime is included.

Historical validation: 30 tests and the clean registry/ledger check passed. The tiny retained demonstration produced 10,000 samples and 22 spikes, with zero/negative controls at zero and identical repetition. These were not rerun during packaging.

The current private delayed-restart campaign is 4/4 independently verified: all 10,720 history records preserved and all 64 comparison pairs matched in each accepted test. These preservation checks do not prove semantic learning or useful memory.
